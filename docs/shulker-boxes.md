# Shulker boxes in the player window

In the player window (**Players** > a player who is online) the inventory and the ender chest show what is in them. **Double click a
shulker box** (or click it and press **Open**) and the window shows what is inside it: the same screen as an ender chest, 3 rows of 9, with the
colour of the box as its title. Back goes to where you came from (Escape does too).

* Items inside the box are moved like in the ender chest: drag one, or click it and then a slot. The same item is added to a stack, two
  different items trade places. **Delete stack** takes an item out of the box for good.
* The change is written to the box itself, so the player has it the next time they open it, also if the box is in their inventory or in
  their ender chest. A box that was emptied is the same as one that was never filled.
* If the box is moved or dropped while you look at it, the window says it is not a shulker box any more and goes back.
* It needs the helper (the Stratosphere plugin or mod) with protocol 9: install it again from the player list when the panel says there is
  a newer one. With an older helper the double click does nothing.
* The same permission as the rest of the player tools: you have to be allowed to use the console of the server to change things.
